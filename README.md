# IM Visit Coder

A tap-through helper for internal medicine office billing: picks E/M, preventive and add-on codes (MDM vs time) for Medicare, Illinois Medicaid and private payers, using CMS 2026 work RVUs.

Open it at https://daikonfuji.github.io/im-visit-coder/ — on Android, Chrome ⋮ menu → Add to Home screen.

Reference tool only, not compliance advice. Contains no patient data.
